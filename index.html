DC Motor Speedometer

Embedded control, sensing & display

Combined PWM motor speed control, optical RPM sensing, and a live OLED readout on the ATmega324PB Xplained Pro for Temple's Processor Systems Lab.

10,650 RPMRecorded at 100% duty cycle
One second measurement window
CMicrocontrollersPWMI²C
Explore the system +

Designed and implemented independently in C. Joystick input selects ten duty cycle levels from 10% to 100%, plus a stopped state.

  • Timer1 generates software PWM on PE2 using a 50 microsecond interrupt interval.
  • INT0 counts optical sensor pulses from a two slot encoder. Timer0 provides a one second measurement window for RPM = pulse count × 30.
  • An I²C OLED displays mode, duty cycle, and speed.
  • Recorded speeds ranged from 3,690 RPM at 10% duty cycle to 10,650 RPM at 100%. PWM timing was checked using Data Visualizer.
